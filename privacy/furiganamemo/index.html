3. 本アプリが端末内に保存する情報

本アプリはアカウント登録なしで利用でき、当社が利用者から氏名・メールアドレス等の情報を直接収集することはありません。本アプリが扱う次のデータは、お使いの端末内のデータベースにのみ保存され、当社のサーバーへ送信されることはありません。当社はこれらのデータにアクセスできません。

5. 広告の表示について

本アプリでは、メモ一覧・メモ編集・単語グループ・設定の各画面にバナー広告を表示します。加えて、利用者が自ら選択して視聴できる動画広告 (リワード広告) があり、視聴すると24時間のあいだ広告の非表示と PDF 出力機能をご利用いただけます。視聴するかどうかは任意で、視聴しなくても本アプリの他の機能は制限なくご利用いただけます。

バナーの枠には、Google AdMob の広告に代えて当社の他のアプリの紹介を表示することがあります。この紹介は当社が用意した情報 (アプリ名・説明・アイコン・ストアへのリンク) を表示するだけで、利用者に関する情報の取得・送信は伴いません。

広告は Google AdMob により配信されます。Google がパートナーとして利用する広告事業者の一覧は「Google の広告テクノロジー プロバイダ」でご確認いただけます。パーソナライズ広告の配信は、適用される法令と利用者の同意・許可の状況 (iOS の ATT、EEA・英国の同意フォーム) に従います。同意または許可が得られていない場合は、広告 ID を用いないパーソナライズされていない広告 (制限付き広告) を配信します。

6. 外部送信について

本アプリが利用者の操作によらず外部へ送信するのは、第4条に記載した第三者 SDK の情報に限られます。当社が運営するサーバーはなく、メモの内容が当社へ送信されることはありません。

このほか、本アプリは第5条の「当社の他のアプリの紹介」を表示するため、当社の Web サイト (qkserve.github.io、GitHub, Inc. の GitHub Pages 上で公開) から紹介情報 (アプリ名・説明・アイコン) を定期的に取得します。この取得は通常の Web ページの閲覧と同じく、GitHub のサーバーに IP アドレス等の接続情報が渡りますが、当社がこれを取得・保存することはなく、利用者の操作内容やメモの内容が送信されることもありません。

「共有」「エクスポート」「PDF 出力」の各機能は、変換したテキストやファイルを OS の共有シート (送信先のアプリを選ぶ画面) に渡すのみであり、その後どのアプリへ渡すか、送信するかどうかは利用者の判断と操作によります。当社がこの共有・エクスポートの内容を取得することはありません。

7. アプリ内課金について

本アプリには、買い切り型 (非消耗型) のアプリ内課金「プレミアム」があります。購入いただくと、広告が表示されなくなり、PDF 出力機能を期限なくご利用いただけます。決済は Apple の App Store または Google Play が処理し、クレジットカード番号等の決済情報を当社が取得することはありません。購入の状況は端末内に保存され、機種変更や再インストールの際は「設定 > プレミアム > 購入を復元」からストアのアカウントを通じて復元できます。購入の履歴・返金等の取り扱いは、各ストア事業者 (Apple / Google) のプライバシーポリシーおよび利用規約に従います。

8. バックアップの取り扱い

本アプリは独自のクラウド同期・バックアップ機能を持ちません。Android では自動バックアップを無効にしているため、本アプリのデータが Google のサーバーへバックアップされることはありません。iOS では、端末の iCloud バックアップが有効な場合、本アプリのデータのコピーが Apple のサーバーに保存され、再インストール時に復元される場合があります。このコピーはアプリを削除しても残るため、不要な場合は iOS のバックアップ設定から削除してください。将来、当社独自のクラウド同期・バックアップ機能を追加する場合は、本ポリシーを改定のうえ本ページで告知します。

9. 同意の管理・オプトアウト

  • iOS (ATT): トラッキングの許可は初回起動時等に表示される ATT ダイアログで選択でき、いつでも iOS の「設定 > プライバシーとセキュリティ > トラッキング」から変更できます。許可されていない場合、本アプリおよび Google が IDFA を用いてアプリを跨いだトラッキングを行うことはありません。
  • EEA・英国等の同意が必要な地域: Google の同意管理プラットフォーム (UMP) による同意フォームが表示されます。同意内容は、アプリ内「設定 > プライバシー > 広告の同意設定」(対象地域でのみ表示) からいつでも変更・撤回できます。同意の撤回は、撤回前に行われた処理の適法性に影響しません。
  • 利用状況分析 (Firebase Analytics): 収集は既定で無効とし、同意が不要な地域の利用者についてのみ有効化します。EEA・英国等の同意が必要な地域では、同意の内容にかかわらず収集しません。Google 同意モード (Consent Mode) の既定値はすべて「拒否」に設定しています。
  • 補助的な OS 設定: Android では「設定 > プライバシー > 広告」から広告 ID のリセット・削除ができます。iOS では上記のトラッキング設定が該当します (いずれも同意の撤回そのものではありません)。

10. 第三者への提供

当社は、法令に基づく場合および本ポリシーに記載する外部サービス提供者 (Google、Apple) への送信を除き、取得した情報を第三者に提供しません。

第4条に記載の SDK を通じて送信される情報は、Google がそのプライバシーポリシーに基づいて取り扱います。処理の内容によっては、Google が独立した管理者として情報を処理する場合があります。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Firebase のプライバシーとセキュリティ
  • Apple プライバシーポリシー (アプリ内課金)

11. 国外へのデータ移転

第4条の SDK の送信先には、米国その他日本国外に所在する Google のサーバーが含まれます。Google は、EU 標準契約条項 (SCC) への準拠をはじめとする適切な保護措置を講じています。移転先および保護措置の詳細は、上記「Firebase のプライバシーとセキュリティ」等でご確認いただけます。第3条の端末内データは移転の対象になりません。
