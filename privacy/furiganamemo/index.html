2. 適用範囲と正本

本ポリシーは本アプリにのみ適用されます。当社の他アプリには当社アプリ共通のプライバシーポリシーが適用され、当社コーポレートサイトのプライバシーポリシーとは独立した文書です。本ポリシーは日本語版を正本とし、翻訳版との間に齟齬がある場合は日本語版が優先します。

3. 本アプリが端末内に保存する情報

本アプリはアカウント登録なしで利用でき、当社が利用者から氏名・メールアドレス等の情報を直接収集することはありません。本アプリが扱う次のデータは、お使いの端末内のデータベースにのみ保存され、当社のサーバーへ送信されることはありません (第5条のバックアップを除く)。当社はこれらのデータにアクセスできません。

4. 外部送信について

本アプリはインターネット通信を行う機能を持たず、当社のサーバーへの通信も発生しません。「共有」「エクスポート」機能は、変換したテキストを OS の共有シート (送信先のアプリを選ぶ画面) に渡すのみであり、その後どのアプリへ渡すか、送信するかどうかは利用者の判断と操作によります。当社がこの共有・エクスポートの内容を取得することはありません。

5. バックアップの取り扱い

本アプリは独自のクラウド同期・バックアップ機能を持ちません。ただし、OS のバックアップ機能 (iCloud バックアップ / Google バックアップ等) が有効な場合、本アプリのデータのコピーが当該 OS 事業者のサーバーに保存され、再インストール時に復元される場合があります。これらのコピーはアプリを削除しても残るため、不要な場合は各 OS のバックアップ設定から削除してください。将来、当社独自のクラウド同期・バックアップ機能を追加する場合は、本ポリシーを改定のうえ本ページで告知します。

6. 第三者 SDK について

本アプリは、広告表示 SDK、利用状況分析 SDK (Firebase Analytics 等)、クラッシュ解析 SDK (Firebase Crashlytics 等) を含め、いかなる第三者 SDK も組み込んでいません。当社および第三者が、本アプリの利用状況や広告 ID 等の識別子を収集することはありません。

お問い合わせをいただいた場合に限り、氏名・メールアドレス等の連絡先、問い合わせ内容、および必要に応じて端末・OS の情報を、お問い合わせ対応の目的で取得します。これらの情報は、対応完了後、合理的な期間の経過後に削除します。

7. 第三者への提供・外部送信

当社は、法令に基づく場合を除き、取得した情報を第三者に提供しません。本アプリは第4条のとおり利用者の操作によらない外部送信を行わないため、広告配信事業者・分析事業者等への情報提供もありません。

8. 国外へのデータ移転

本アプリは情報を当社のサーバーまたは第三者のサーバーへ送信しないため、本アプリの利用に伴う国外へのデータ移転はありません。

本アプリは端末内でのみデータを処理し、当社が本アプリを通じて個人データを取得・保存することはありません (第6条のお問い合わせ対応を除く)。お問い合わせいただいた際に取得する情報の処理は、お問い合わせへの対応 (契約締結前の措置に準じるもの) または当社の正当な利益 (適切な対応の実施) を法的根拠とし、対応完了後、合理的な期間の経過後に削除します。

  • 端末内データへのアクセス: メモ・単語グループ・フォルダ・設定は、アプリ内の操作でいつでも閲覧・編集・削除いただけます。
  • 権利: お問い合わせ情報についてアクセス、訂正、消去、処理の制限、異議申立ての各権利を有します。行使は第12条の窓口で受け付けます。

  • 自動化された意思決定: 法的効果を伴う自動化された意思決定 (プロファイリングを含む) は行いません。
