GRAVIS プライバシーポリシー

2. 適用範囲と正本

本ポリシーは本アプリにのみ適用されます。当社の他アプリには当社アプリ共通のプライバシーポリシーが適用され、当社コーポレートサイトのプライバシーポリシーとは独立した文書です。本ポリシーは日本語版を正本とし、翻訳版との間に齟齬がある場合は日本語版が優先します。

3. 本アプリが端末内に保存する情報

本アプリはアカウント登録なしで利用でき、当社が利用者から氏名等の情報を直接収集することはありません。本アプリが扱う次のデータは、お使いの端末内にのみ保存され、当社のサーバーへ送信されることはありません (OS のバックアップを除く)。

データ利用目的
食事の記録 (食品名・量・カロリー・たんぱく質・脂質・炭水化物・食事区分・日時) と、食事のテンプレート摂取カロリーと栄養素の表示
トレーニングの記録 (種目・回数・時間・重量・日時) と、トレーニングのメニュー消費カロリーの計算と記録の表示
身長・体重・年齢・性別・身体活動レベル・目標の収支基礎代謝と1日の摂取の目安の計算
体重の記録計算に使う体重の保持
休憩時間などの設定設定の保持
ストアレビューの依頼を出した記録依頼を出し過ぎないための管理

アンインストールにより端末上のこれらのデータは削除されますが、OS のバックアップ機能 (iCloud バックアップ等) に保存されたコピーは、Apple の設定・保持期間に従って残存し、再インストール時に復元される場合があります。

本アプリに同梱する食品のデータ (文部科学省「日本食品標準成分表」) は端末内で検索するもので、検索した言葉が端末の外へ送信されることはありません。

4. ヘルスケアから読み取る情報

本アプリは、利用者が許可した場合に限り、Apple の「ヘルスケア」から、日常活動で消費したエネルギー (アクティブエネルギー) を読み取ります。

  • 読み取った情報は、1日の消費カロリーの計算と表示にだけ使い、端末内で処理します。当社のサーバーや第三者へ送信することはありません。
  • 読み取った情報を、広告の配信、マーケティング、第5条の SDK に渡すことには使いません。
  • 本アプリがヘルスケアにデータを書き込むことはありません。
  • 許可しなくても本アプリは利用できます (消費カロリーに日常活動の分が含まれなくなります)。

5. 第三者 SDK が取得する情報

本アプリは広告表示のため以下の第三者 SDK を利用しており、この SDK が次の情報を自動的に取得し、Google LLC およびその関連会社 (以下「Google」) のサーバーへ送信します。この SDK に、第3条のデータと第4条のヘルスケアの情報を渡すことはありません。

SDK取得される主な情報利用目的
Google AdMob
(広告配信。バナー)		広告 ID (IDFA。取得は OS の設定・法令・利用者の同意状況により許可される場合に限られます)、広告の表示・操作イベント、IP アドレス (おおよその位置の推定を含む)、端末情報 (機種・OS バージョン等)、クラッシュログ・パフォーマンス情報広告の配信、効果測定、不正防止、SDK の不具合の解析

また、お問い合わせをいただいた場合、氏名・メールアドレス等の連絡先、問い合わせ内容、および必要に応じて端末・OS の情報を、お問い合わせ対応の目的で取得します。これらの情報は、対応完了後、合理的な期間の経過後に削除します。

6. 第三者への提供・外部送信

当社は、法令に基づく場合および本ポリシーに記載する外部サービス提供者 (Google) への送信を除き、取得した情報を第三者に提供しません。

第5条に記載の SDK を通じて送信される情報は、Google がそのプライバシーポリシーに基づいて取り扱います。処理の内容によっては、Google が独立した管理者として情報を処理する場合があります。パーソナライズ広告およびアプリを跨いだトラッキングの実施は、適用される法令と利用者の同意状況 (iOS の ATT) に従います。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用

7. 国外へのデータ移転

第5条の送信先には、米国その他日本国外に所在する Google のサーバーが含まれます。移転先および保護措置の詳細は、Google のプライバシーポリシーでご確認いただけます。

8. 同意の管理・オプトアウト

  • iOS (ATT): トラッキングの許可は ATT ダイアログで選択でき、いつでも iOS の「設定 > プライバシーとセキュリティ > トラッキング」から変更できます。
  • ヘルスケア: ヘルスケアの読み取りの許可は、iOS の「設定 > アプリ > ヘルスケア > データアクセスとデバイス > GRAVIS」から、いつでも取り消せます。
