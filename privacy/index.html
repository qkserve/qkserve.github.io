3. 収集する情報と利用目的

当社アプリはアカウント登録なしで利用でき、当社が利用者から氏名等の情報を直接収集することはありません。一方、当社アプリは広告表示・品質改善のため以下の第三者 SDK を利用しており、これらの SDK が次の情報を自動的に取得し、Google LLC およびその関連会社 (以下「Google」) のサーバーへ送信します。

4. アプリ内データの取り扱い

スキャン履歴など、利用者が当社アプリ内で作成・保存するデータは、利用者の端末内にのみ保存され、当社のサーバーへ送信されることはありません。これらのデータはアプリ内で削除できます。

アンインストールにより端末上のデータは削除されますが、OS のバックアップ機能 (iCloud バックアップ / Google バックアップ等) に保存されたコピーは、当該 OS 事業者の設定・保持期間に従って残存し、再インストール時に復元される場合があります。

5. 第三者への提供・外部送信

当社は、法令に基づく場合および本ポリシーに記載する外部サービス提供者 (Google 等) への送信を除き、取得した情報を第三者に提供しません。

第3条に記載の SDK を通じて送信される情報は、Google がそのプライバシーポリシーに基づいて取り扱います。処理の内容によっては、Google が独立した管理者として情報を処理する場合があります。パーソナライズ広告およびアプリを跨いだトラッキングの実施は、適用される法令と利用者の同意状況 (iOS の ATT、同意フォーム) に従います。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Firebase のプライバシーとセキュリティ

6. 国外へのデータ移転

第3条の SDK の送信先には、米国その他日本国外に所在する Google のサーバーが含まれます。Google は、EU 標準契約条項 (SCC) への準拠をはじめとする適切な保護措置を講じています。移転先および保護措置の詳細は、上記「Firebase のプライバシーとセキュリティ」等でご確認いただけます。

7. 同意の管理・オプトアウト

  • iOS (ATT): トラッキングの許可は ATT ダイアログで選択でき、いつでも iOS の「設定 > プライバシーとセキュリティ > トラッキング」から変更できます。
  • EEA・英国等の同意が必要な地域: 法令に基づく同意フォームが表示されます。同意内容は、アプリ内「設定 > 広告のプライバシー設定」(対象地域でのみ表示) からいつでも変更・撤回できます。同意の撤回は、撤回前に行われた処理の適法性に影響しません。
  • 利用状況分析: Firebase Analytics による利用状況データの収集は、同意が必要な地域では行いません。
  • 補助的な OS 設定: Android では OS の設定から広告 ID のリセット・削除ができます (同意の撤回そのものではありません)。
