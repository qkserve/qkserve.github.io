2. 適用範囲と正本

本ポリシーは本アプリにのみ適用されます。当社の他アプリには当社アプリ共通のプライバシーポリシーが適用され、当社コーポレートサイトのプライバシーポリシーとは独立した文書です。本ポリシーは日本語版を正本とし、翻訳版との間に齟齬がある場合は日本語版が優先します。

3. 本アプリが端末内に保存する情報

本アプリはアカウント登録なしで利用でき、当社が利用者から氏名等の情報を直接収集することはありません。本アプリが扱う次のデータは、お使いの端末内に保存され、当社のサーバーへ送信されることはありません (第5条のバックアップを除く)。当社はこれらのデータにアクセスできません。

4. 位置情報の取り扱い

本アプリのコア機能は移動ルートと行動の自動記録であり、アプリを閉じている間も記録を継続するためにバックグラウンドでの位置情報の取得が必要です。位置情報の取得は、OS の権限ダイアログで利用者が許可した場合にのみ行われ、端末の設定からいつでも変更・停止できます。

取得した位置情報は端末内での記録・判定・表示にのみ使用します。当社のサーバーへ送信することはなく、広告の配信・ターゲティングその他の目的で第三者へ提供することもありません。

5. バックアップの取り扱い

本アプリには、利用者ご自身の操作で位置情報・歩数・行動ログを iCloud へバックアップする機能があります (iOS)。この機能を利用した場合、データは利用者ご自身の iCloud アカウントに保存されます。保存先は Apple が提供するストレージであり、当社はその内容にアクセスできません。

また、OS のバックアップ機能 (iCloud バックアップ / Google バックアップ等) が有効な場合、本アプリのデータのコピーが当該 OS 事業者のサーバーに保存され、再インストール時に復元される場合があります。これらのコピーはアプリを削除しても残るため、不要な場合は各 OS のバックアップ設定から削除してください。

6. ヘルスケアデータの取り扱い

本アプリは、利用者の許可に基づき Apple ヘルスケア (HealthKit) または Android ヘルスコネクトから歩数データを読み取ります。要求するのは読み取り権限のみで、これらへの書き込みは行いません。

ヘルスケアデータを広告・マーケティングの目的で使用することはなく、第三者へ提供・販売することもありません。これらのデータは端末内での歩数表示と統計にのみ使用します。許可は端末のヘルスケア設定からいつでも取り消せます。

本アプリは広告表示・品質改善のため以下の第三者 SDK を利用しており、これらの SDK が次の情報を自動的に取得し、Google LLC およびその関連会社 (以下「Google」) のサーバーへ送信します。

本アプリは Firebase Analytics 等の利用状況分析 SDK を利用していません。また、第3条の位置情報・歩数・行動ログがこれらの SDK へ渡されることはありません。AdMob が推定する「おおよその位置」は IP アドレスに基づくものであり、本アプリが取得する GPS 位置情報とは別のものです。

また、お問い合わせをいただいた場合、氏名・メールアドレス等の連絡先、問い合わせ内容、および必要に応じて端末・OS の情報を、お問い合わせ対応の目的で取得します。これらの情報は、対応完了後、合理的な期間の経過後に削除します。

8. 第三者への提供・外部送信

当社は、法令に基づく場合および本ポリシーに記載する外部サービス提供者 (Google 等) への送信を除き、取得した情報を第三者に提供しません。

第7条に記載の SDK を通じて送信される情報は、Google がそのプライバシーポリシーに基づいて取り扱います。処理の内容によっては、Google が独立した管理者として情報を処理する場合があります。パーソナライズ広告およびアプリを跨いだトラッキングの実施は、適用される法令と利用者の同意状況 (iOS の ATT、同意フォーム) に従います。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Firebase のプライバシーとセキュリティ

9. 国外へのデータ移転

第7条の SDK の送信先には、米国その他日本国外に所在する Google のサーバーが含まれます。Google は、EU 標準契約条項 (SCC) への準拠をはじめとする適切な保護措置を講じています。移転先および保護措置の詳細は、上記「Firebase のプライバシーとセキュリティ」等でご確認いただけます。

10. 同意の管理・オプトアウト

  • 位置情報・ヘルスケア・モーション: 各権限は OS の設定からいつでも変更・停止できます。停止した場合、ルート記録や歩数取得など該当機能は利用できなくなります。
  • iOS (ATT): トラッキングの許可は ATT ダイアログで選択でき、いつでも iOS の「設定 > プライバシーとセキュリティ > トラッキング」から変更できます。
  • EEA・英国等の同意が必要な地域: 法令に基づく同意フォームが表示されます。同意内容は、アプリ内「設定 > 広告のプライバシー設定」(対象地域でのみ表示) からいつでも変更・撤回できます。同意の撤回は、撤回前に行われた処理の適法性に影響しません。
  • 補助的な OS 設定: Android では OS の設定から広告 ID のリセット・削除ができます (同意の撤回そのものではありません)。
